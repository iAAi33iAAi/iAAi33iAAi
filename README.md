## Architecture

**AETHEL** — protocol, state, invariants, evidence and conformance rules.

**CAIOS** — proposed/advisory control-plane reasoning and admission architecture; it is not treated as self-certifying.

**Execution repositories** — individual implementations and adapters such as OpenClaw Colony, Safety Kernel, project-mono and World-Tribe Protocol.

Implementation in one repository does not by itself establish cross-repository conformance.

---

## Evidence Policy

1. Constitutional / normative specification
2. Canonical schema
3. Ratified test vectors
4. Independent reference validator
5. Implementation conformance result
6. Runtime attestation and execution evidence
7. Design documentation
8. Investor / marketing material

A lower-authority README statement must not override higher-authority evidence.
